# Logos — Dr. Fábio Matheus

Cinco propostas de logo construídas sobre a Identidade Visual FM (monograma F + M com cúspide e ponto,
paleta monocromática Ônix / Branco / Esmalte / Névoa / Grafite, Jost Light espaçada).

| Arquivo | Conceito |
| --- | --- |
| `01-assinatura-cuspide` | Assinatura vertical oficial, positivo |
| `02-selo-esmalte` | Selo circular com nome em arco, negativo |
| `03-arco` | Horizontal, monograma sob um arco, fundo Esmalte |
| `04-tipografica-cuspide` | Somente letras; o M de MATHEUS vira cúspide com ponto |
| `05-traco-unico` | Monograma em traço contínuo, fundo Grafite |

Os SVGs têm o texto convertido em contorno e renderizam igual em qualquer lugar. Os PNGs são prévias.

Para regerar: baixe `Jost[wght].ttf` (Google Fonts, licença OFL) como `Jost.ttf` ao lado de `gen.py`,
instale `fonttools` e rode `python3 gen.py <pasta-de-saída>`.
